6.A Test Procedure for Images with a non-empty text alternative

Baseline Test ID: {{ page.source }}-6.A-MeaningfulImage

Identify Content

Identify any image {% if page.source == "Web" %}(i.e., img element or an element with role="img"){% endif %} that has a non-empty text alternative{% if page.source == "Web" %} (combination of the accessible name and accessible description) per the HTML Accessibility API Mappings 1.0 for img{% endif %}.

Test Instructions

  1. Check that none of the following is true [SC 1.1.1]:
    1. The image is page design/formatting and could be ignored by assistive technology without any loss of meaning.
    2. The image is not visible on the page.
    2. {% if page.source == "Web" %}
  2. Check that the ARIA role is NOT "presentation".[SC 4.1.2]
  3. Check that the ARIA role is NOT "none".[SC 4.1.2]
    4. {% endif %}
  4. Check that the non-empty text alternative {% if page.source == "Web" %}(combination of accessible name and accessible description){% endif %}provides an equivalent description of the image's purpose. [SC 1.1.1]

Test Results

If any of the above checks fail, then Baseline Test {{ page.source }}-6.A-MeaningfulImage fails.
